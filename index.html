Пример 1

Рассмотрим функцию \(f(x)= x^3 - 3x \)

  1. Область определения и область значения

    2. \(D(f)=(-\infty;+\infty)\)
    \(E(f)=(-\infty; +\infty)\)

  2. Четность и периодичность

    3. \(f(-x) = (-x)^3 - 3(-x) = -x^3 + 3x = - (x^3 - 3x) = -f(x)\) - нечетная

  3. Точки пересечения с осями

    4. \(f(0) = 0^3 -3\cdot0 = 0\)

    \(f(x) = 0\): \(x^3 - 3x = 0\)
         \(x(x^2-3)=0\)
      \(x=0\); \(x^2-3=0\)
        \((x-\sqrt{3})(x+\sqrt{3})=0\)
        \(x=\sqrt{3}\); \(x=-\sqrt{3}\)
    \((-\sqrt{3};0), (0;0), (\sqrt{3};0)\)

  4. Асимптоты

    5. Так как \(D(f) = (-\infty;+\infty)\), то вертикальных асимптот нет.

    Наклонные и горизонтальные асимптоты (\(y = kx + b\)):

     \( k = \lim\limits_{x \to \pm\infty} \dfrac{f(x)}{x} = \lim\limits_{x \to \pm\infty} \dfrac{x^3 - 3x}{x} = \lim\limits_{x \to \pm\infty} (x^2 - 3) = +\infty \)

    Так как предел равен бесконечности, наклонных и горизонтальных асимптот нет.

    Асимптот нет.

  5. Экстремумы

    6. Найдем производную функции:
     \( f'(x) = (x^3 - 3x)' = 3x^2 - 3 \)

    Найдем критические точки (\(f'(x)=0)\):
     \(3x^2 - 3 = 0 \implies 3(x^2 - 1) = 0 \)
     \( 3(x - 1)(x + 1) = 0 \)
       \( \left[ \begin{array}{l} x = -1 \\ x = 1 \end{array} \right.\)

    Определим знаки производной на интервалах:

    \(x = -1\) - точка максимума;
    \(x = 1\) - точка минимума;

    \(f(-1) = (-1)^3 - 3(-1) = -1 + 3 = 2\)
    \(f(1) = 1^3 - 3\cdot1 = 1 - 3 = -2\)

    Экстремумы: \((-1; 2)\), \((1; -2)\)
